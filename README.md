# Weather-app
# 🌤️ Weather App UI Design

## ✨ Project Overview

This is a **Weather App UI Design** created using **Figma**. The application provides users with simple and clear information about the current weather, temperature, humidity, wind speed, and upcoming weather conditions.

## 🎯 Objective

The main objective of this project is to design a **simple, attractive, and user-friendly weather application** that helps users quickly understand the current and future weather conditions.
